# 弹幕桥

**让YouTube直播链接Bilibili弹幕**

将已打开的 B 站直播间的新弹幕，显示在指定的 YouTube 视频或直播播放器上。当前版本：**v0.1.8**。

这是独立的非官方浏览器扩展，与 Bilibili、YouTube、Google 或 Microsoft 无隶属或背书关系。

## 功能

- 为不同的 YouTube 标签页绑定不同的 B 站直播间，在同一浏览器内转发弹幕。
- 优先复用上方安全轨道，按文字及图片的实际宽高检查重叠和追尾。
- 支持字号、透明度、滚动时长、显示区域和发送者昵称设置。
- 支持读取到的原始弹幕颜色，也可关闭「显示弹幕颜色」，让新文字弹幕统一显示为白色。
- 支持已识别的表情标记与图片混排；普通表情为原始基准的 100%，识别为特殊类型的表情为 180%。
- 修改显示设置只影响之后出现的新弹幕，已经显示的弹幕继续原样滚动。关闭显示开关则立即清屏。
- 连接成功后显示「连接成功」，并提供断开操作。

## 从源码安装

适用于电脑端 Chrome 和 Microsoft Edge。

1. 点击本仓库的 **Code → Download ZIP**，并解压到一个固定位置；也可以使用 Git 克隆仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」（Edge 中可能显示为「加载解压缩的扩展」）。
4. 选择仓库内的 **`bili-youtube-danmaku` 文件夹**，该文件夹中包含 `manifest.json`。不要选择仓库根目录。
5. 刷新已经打开的 B 站和 YouTube 标签页。

请保留加载时选择的文件夹。仓库根目录的 `弹幕桥-v0.1.4.zip` 是旧安装包，最新源码版本以 `bili-youtube-danmaku/manifest.json` 为准。

## 使用

1. 打开一个 B 站直播间，确保聊天区正常加载且有新消息。按 B 站页面提示登录（如需要）。保留该标签页，可以静音。
2. 打开 YouTube 视频或直播并播放。
3. 点击工具栏的弹幕桥图标，分别选择目标 YouTube 页面和来源 B 站直播间。
4. 点击「连接直播间」。绑定成功后按钮显示「连接成功」。
5. 点击「发送测试弹幕」检查播放器弹幕层；然后等待 B 站的新弹幕。
6. 如需识别更多表情，在 B 站展开表情面板并停留约一秒。切换表情分页可以继续学习。

测试弹幕成功只表示显示链路可用，不代表已成功收到 B 站的新消息。插件不会补发页面加载前的聊天历史。

一个 YouTube 标签页绑定一个来源；多个目标页可分别绑定。切换源直播间、关闭相关标签页或重启浏览器后，请检查并重新绑定。

## 设置说明

| 设置 | 行为 |
| --- | --- |
| 显示弹幕 | 关闭后立即清空弹幕层并停止显示 |
| 显示弹幕颜色 | 开启时使用可读取到的消息颜色；关闭时新文字弹幕统一白色，表情图片保留自身颜色 |
| 字号、透明度、滚动时长、显示区域 | 只作用于新出现的弹幕 |
| 显示发送者昵称 | 控制昵称是否显示；不改变源页面的昵称读取 |

B 站播放器中的「只看白色弹幕」等显示设置不会强制覆盖插件读取到的原始消息颜色。请用插件自己的颜色开关控制。

普通表情的 100% 基准为字号的 1.15 倍；特殊表情为同一基准的 180%，即字号的 2.07 倍。特殊类型通过消息元数据和页面线索识别，不保证识别全部粉丝团或自定义表情。

## 已知限制与排查

- **需要保留 B 站标签页。** 浏览器休眠源标签页后可能停止采集，可将直播间加入浏览器的内存节省排除列表。
- **不对齐播放时间。** 两个平台的直播延迟不同，弹幕可能先于或晚于 YouTube 的画面；暂停和回看也不会自动校准。
- **仍可能漏色。** 消息元数据和聊天节点可能无法匹配；已加入最多约 450ms 的等待和播放器颜色回退，但未捕获到可靠颜色时仍可能显示白色。
- **表情并非完整离线库。** 依赖页面提供的名称和图片地址，首次下载较慢或失败时会保留文字标记占位。礼物、付费醒目留言及无可读标记的图片消息不保证支持。
- **热门直播可能丢弃消息。** 有队列上限及过期机制，优先避免覆盖画面和长时间积压。
- **支持网页播放器内全屏。** 系统画中画窗口无法使用网页弹幕层。
- **依赖 B 站页面及消息解析方式。** 页面改版、实验界面或区域访问差异可能影响功能。
- **更新必须刷新页面。** 更新源码后在扩展管理页重新加载，再完整刷新 B 站与 YouTube 页面并重新连接；仅重新打开弹窗不能启用新的采集脚本。

## 隐私与权限

弹幕文字、昵称和匹配信息在本机临时处理，不上传到开发者运营的服务器，不持久化为聊天历史。插件不自动发言，也不读取账号密码或 Cookie。

显示偏好、表情地址映射和特殊类型分类保存在扩展本地存储；绑定及采集状态保存在会话存储。关闭显示开关不等同于停止源页面采集；如需停止访问，请禁用扩展、撤销网站权限或关闭页面。

表情图片从 B 站 `hdslb.com` 图片 CDN 下载，请求不携带账号凭据和来源页面信息，也不发送弹幕正文或昵称。CDN 仍会接收正常网络请求附带的 IP 地址和连接信息。

所需权限仅包括扩展存储，以及 B 站直播、YouTube 和图片 CDN 的网站访问权限。详见仓库中的 [隐私政策](index.html)；正式商店中的政策链接应指向其公开发布的网页。

## 源码结构

所有扩展运行文件位于 `bili-youtube-danmaku/`：

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 版本、权限、脚本入口与图标配置 |
| `background.js` | 标签页绑定、本机转发与表情图片下载 |
| `page-meta.js` | 观察页面已解码直播消息中的颜色及表情元数据 |
| `source.js` | 聊天节点采集、颜色匹配和表情映射学习 |
| `emoji.js` | 表情、颜色与资源地址校验 |
| `layout.js` | 弹幕位置与碰撞计算 |
| `overlay.js` | YouTube 弹幕层与图片渲染 |
| `popup.html`、`popup.css`、`popup.js` | 设置及连接界面 |
| `icons/` | v3 图标：「弹」在左，独立横线在右 |
