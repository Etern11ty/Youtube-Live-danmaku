# 弹幕桥·bilibili直播弹幕转接youtube

**让YouTube直播链接Bilibili弹幕**

在 YouTube 直播播放器上观看 Bilibili 直播间的实时弹幕。目前仅适用于直播页面。

[**Edge 用户：从扩展商店安装**](https://microsoftedge.microsoft.com/addons/detail/%E5%BC%B9%E5%B9%95%E6%A1%A5%C2%B7bilibili%E7%9B%B4%E6%92%AD%E5%BC%B9%E5%B9%95%E8%BD%AC%E6%8E%A5youtube/pahnmkihokfhhiekbledcjanpkechoha)

[下载 v0.1.16 安装包](弹幕桥-v0.1.16.zip) · [重要更新](#重要更新) · [反馈问题](https://github.com/Etern11ty/Youtube-Live-danmaku/issues)

商店版与仓库版的更新进度可能不同。仓库当前版本为 **v0.1.16**。

## 功能

- 支持 YouTube 桌面网页与移动网页（`www.youtube.com` / `m.youtube.com`）。
- 支持后台直连：输入房间号或 Bilibili 直播间链接，无需打开 B 站标签页。
- 也可绑定已打开的 Bilibili 直播间标签页，实时转接新弹幕。
- 后台直连支持匿名接收、连接状态与断线重连。
- 支持通过内嵌直播播放器展示的赛事活动页，弹窗可显示当前内嵌房间的采集状态。
- 支持彩色弹幕，也可切换为白色文字。
- 支持可识别的 B 站表情，已下载的图片保留到本机缓存。
- 可调节字号、透明度、滚动时长、显示区域和昵称显示。
- 修改样式只影响新弹幕，不打断正在滚动的弹幕。
- 自动安排弹幕轨道，减少文字和表情重叠。

## 安装

### Microsoft Edge

打开 [Edge 扩展商店页面](https://microsoftedge.microsoft.com/addons/detail/%E5%BC%B9%E5%B9%95%E6%A1%A5%C2%B7bilibili%E7%9B%B4%E6%92%AD%E5%BC%B9%E5%B9%95%E8%BD%AC%E6%8E%A5youtube/pahnmkihokfhhiekbledcjanpkechoha)，点击「获取」并确认安装。

### Chrome 或手动安装

1. 下载上方安装包并解压到固定文件夹。
2. 打开 `chrome://extensions`；Edge 手动安装时打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后直接包含 `manifest.json` 的文件夹。
5. 刷新已打开的 Bilibili 和 YouTube 页面。

也可以通过 **Code → Download ZIP** 下载整个仓库，解压后选择其中的 **`bili-youtube-danmaku`** 文件夹。保留该文件夹，以免手动加载的扩展失效。

## 使用

先打开并播放 YouTube 直播，点击弹幕桥图标，选择目标 YouTube 页面。

### 后台直连

1. 将「连接方式」设为「后台直连」。
2. 输入房间号，例如 `22637261`，或完整链接，例如 `https://live.bilibili.com/22637261`。
3. 点击「连接直播间」，等待显示「连接成功」。此模式无需打开 B 站标签页，也无需登录。
4. 赛事页面请填写所选主播的实际房间号。输入赛事入口链接会连接入口房间，不会自动跟随页面切换主播。

连接断开后会自动重试；点击「断开」可停止后台接收。浏览器重启后需要重新连接，上次输入与连接方式会保留。

### 绑定标签页

1. 打开 Bilibili 直播间，确认聊天区能收到新弹幕。
2. 将「连接方式」设为「绑定标签页」，选择 B 站直播间并连接。
3. 保留 B 站标签页；需要时展开表情面板，停留片刻以识别更多表情。

直连遇到访问限制时，可切换为绑定标签页。切换方式后点击连接，才会替换当前来源。

「发送测试弹幕」可检查 YouTube 弹幕层是否正常显示。测试成功不代表已经收到 B 站消息。

## 移动端

在能安装本扩展的移动浏览器中打开 YouTube 网页，选择该页面后使用后台直连，不必切换为桌面版网站。设置面板适配窄屏与触摸操作。

本次补充的是移动网页适配，不能给 YouTube App 叠加弹幕，也不代表所有手机浏览器都支持安装本扩展。iPhone/iPad 版 Edge 已有扩展功能，但弹幕桥是否可安装、后台连接是否受限仍需对应设备验证。

横竖屏切换或网页播放器尺寸变化后，会清理旧轨道并在新尺寸内继续显示。系统原生视频全屏及画中画可能不携带网页弹幕层；优先使用网页播放器内的全屏。

## 设置

| 设置 | 作用 |
| --- | --- |
| 显示弹幕 | 开关弹幕层，关闭时立即清屏 |
| 显示弹幕颜色 | 关闭后，新文字弹幕统一白色；表情图片颜色不变 |
| 字号、透明度、滚动时长、显示区域 | 调整之后出现的新弹幕 |
| 显示发送者昵称 | 控制是否在弹幕前显示昵称 |

插件的颜色开关独立于 B 站播放器设置。即使 B 站设为只显示白色，插件仍可能读取到消息原始颜色。

## 使用限制

- **标签页模式需要保留来源页面。** 关闭或休眠后可能停止转接；后台直连不依赖 B 站标签页。
- **后台直连依赖匿名接口。** 接口签名、访问限制或协议变化可能影响连接；需要 Chrome / Edge 116 或更新版本。
- **不对齐直播时间。** 两个平台的延迟不同，弹幕可能先于或晚于画面。暂停、回看时不会自动校准。
- **只显示新消息。** 不补发历史弹幕，不向任一平台发送聊天消息。
- **颜色和表情可能缺失。** 未能读取颜色时可能显示白色；未识别或下载失败的表情保留文字标记。礼物、付费醒目留言及部分图片消息暂不保证支持。
- **高流量时可能丢弃消息。** 弹幕队列设有数量及等待时间上限。
- **不支持系统画中画。** 网页播放器内全屏可显示弹幕层。
- **页面变化可能影响功能。** B 站改版、实验界面或访问限制可能导致采集异常。

切换源直播间或重启浏览器后，请重新检查连接。关闭目标 YouTube 标签页会停止该页面的直连。手动更新扩展时，先在扩展管理页重新加载，刷新 YouTube 页面后重新连接；标签页模式还需刷新 B 站页面。

## 隐私

弹幕文字和昵称在同一浏览器内临时处理，不上传到开发者服务器，不保存为聊天历史。显示设置、连接方式、上次输入和表情映射保存在本机。后台直连会访问 B 站接口及弹幕服务器，表情图片从 B 站图片 CDN 下载。昵称显示开关仅控制显示，不停止读取昵称。

关闭弹幕显示不等于停止接收。后台直连可通过「断开」停止；标签页采集可通过关闭来源页、禁用扩展或撤销网站权限停止。详见 [隐私政策](index.html)。

本项目为非官方扩展，与 Bilibili、YouTube、Google 或 Microsoft 无隶属或背书关系。

## 重要更新

### v0.1.16 · 移动版 YouTube 网页

- 新增 `m.youtube.com` 的页面识别、来源校验、图片下载和直连恢复支持。
- 补充移动播放器定位，跟随播放器替换与网页容器全屏；尺寸变化时重新安排轨道。
- 设置面板适配窄屏，增大触摸操作区域。
- 新增移动版 YouTube 网站访问权限，更新后浏览器可能要求确认。


### v0.1.15 · 后台直连与来源切换

- 新增后台直连，支持输入房间号或完整直播间链接，无需保留 B 站标签页。
- 保留绑定标签页模式，可在两种方式之间切换。
- 显示连接、重连状态及接收计数，断线后自动重试；断开或关闭目标页面后停止连接。
- 直接解析消息中的原始颜色与表情信息，继续使用现有排版和图片缓存。
- 新增 B 站接口访问权限和定期恢复连接权限；更新后浏览器可能要求确认新增权限。


### v0.1.14 · 特殊图片表情

- 修复无名称的纯图片表情被跳过，以及图片地址延迟加载后无法采集的问题。
- 补充整条图片消息和嵌套表情信息的替换，保留图文顺序，减少同名表情图片映射冲突。
- 图片下载上限提高到 512KiB，并同步调整显示端限制，继续使用本机持久缓存。

更新后重新加载扩展，刷新 Bilibili 与 YouTube 页面并重新连接。

### v0.1.13 · 弹幕吞吐与表情缓存

- 保留靠上排列，改为每 30ms 逐条入场，安全轨道充足时最高约 33 条/秒，减少同时入场形成的竖列和波次感。
- 横向最小安全间隔由 24px 缩小至 16px，保留追尾检查。
- 等待表情下载的消息不再阻塞后面的文字。
- 已下载的表情图片保存到本机持久缓存，后台重启后可复用；最多缓存 200 张，淘汰或清除后重新下载。
- 设置名称、滑块和数值改为同行显示，缩短面板。

### v0.1.12 · 赛事直播页

- 支持赛事活动页内嵌直播间的弹幕采集。
- 分别记录外层页面和内嵌直播间状态，避免显示错误的“采集状态未更新”。
- 弹窗显示当前内嵌房间号，减少跨页面重复弹幕。

更新后需重新加载扩展、刷新赛事页和 YouTube 页面，再重新连接。

### v0.1.10 · 更新后旧脚本退出

- 处理重新加载扩展后反复出现的 `Extension context invalidated` 错误。
- 旧脚本失效时停止采集定时器和页面观察，清理旧弹幕层。更新后仍需刷新相关标签页。

### v0.1.7 · 颜色开关与连接状态

- 新增“显示弹幕颜色”开关，可将新文字弹幕统一显示为白色。
- 改善颜色元数据的延迟匹配，减少漏色。
- 调整表情显示尺寸。
- 绑定成功后按钮显示“连接成功”，切换来源或断开后恢复。

### v0.1.6 · 原始弹幕颜色

- 增加原始消息颜色读取，并尝试匹配播放器中的弹幕颜色，补充聊天栏颜色信息。
- 利用消息元数据识别更多特殊表情。未读取到可靠信息时，仍可能出现白色弹幕或未识别表情。

### v0.1.3 · 表情显示

- 支持识别 B 站页面中的表情标记并显示对应图片，可与文字混排。
- 保存本机表情映射，图片不可用时保留文字标记。

### v0.1.2 · 紧凑轨道排列

- 优先复用靠上的安全轨道，同轨有碰撞或追尾风险时才向下开行。
- 减少低流量时弹幕过度分散的问题。

### v0.1.1 · 设置修改不清屏

- 字号、透明度等设置只影响新出现的弹幕，已显示的弹幕继续滚动。
- 按实际文字尺寸和速度检查间距，支持混合字号下的轨道避让。

## 源码

扩展运行文件位于 `bili-youtube-danmaku/`。版本与权限见 `manifest.json`；YouTube 页面与播放器识别见 `youtube.js`，后台直连见 `direct.js`，页面采集见 `source.js`、`page-meta.js`；弹幕显示与轨道安排见 `overlay.js`、`layout.js`。
