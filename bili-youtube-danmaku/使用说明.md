# 弹幕桥 0.1.15

将 Bilibili 直播弹幕显示在 YouTube 直播播放器上，不发送聊天消息，不对齐两边的直播延迟。

## 手动安装与更新

1. 解压到固定文件夹，打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启开发者模式，选择「加载已解压的扩展程序」，选中直接包含 `manifest.json` 的文件夹。
3. 更新时替换文件后重新加载扩展，允许新增的 B 站接口访问权限，再刷新 YouTube 页面。

需要 Chrome / Edge 116 或更新版本。请保留解压后的文件夹。

## 后台直连

1. 打开并播放 YouTube 直播，点击扩展图标，选择目标页面。
2. 连接方式选择「后台直连」。
3. 输入房间号或完整链接，例如 `22637261` 或 `https://live.bilibili.com/22637261`。
4. 点击「连接直播间」，等待连接成功和新弹幕。

无需登录或打开 B 站标签页。赛事请填写所选主播的实际房间号；赛事入口链接不会自动跟随页面切换主播。直连断开后会自动重试，点击「断开」可停止接收。关闭目标 YouTube 标签页也会停止相应直连。

## 绑定标签页

1. 打开 B 站直播间，确认聊天区能看到新消息。
2. 连接方式选择「绑定标签页」，选择来源页面后连接。
3. 保留 B 站标签页。更新扩展后，还需刷新 B 站页面。

可在两种方式之间切换，点击连接后才替换当前来源。后台直连遇到接口限制时可使用标签页模式。浏览器重启后需重新连接，上次输入和连接方式会保留。

## 设置与排查

- 「发送测试弹幕」只验证 YouTube 显示是否正常，不代表收到真实 B 站消息。
- 字号、透明度、时长、颜色和区域设置只影响新弹幕。关闭显示开关会清屏，但不会断开连接。
- 没有消息时先查看状态、房间号和新消息计数。未开播或安静的房间可能没有新弹幕。
- 表情下载失败时保留文字标记，已下载图片保存在本机缓存中。
- 高流量时可能丢弃拥堵或等待过久的消息，不补发历史消息。
- 支持播放器内全屏，不支持系统画中画。

## 隐私

弹幕在本机临时转发，不上传到开发者服务器、不保存聊天历史。后台直连匿名访问 B 站房间接口与弹幕服务器，不读取或写入浏览器账号 Cookie。表情图片请求 B 站图片 CDN，最多持久缓存 200 张。B 站服务器仍会收到房间号及正常网络连接信息，例如 IP 地址。

显示设置、连接方式、上次输入和表情映射保存在扩展本地存储中；连接绑定及状态保存在会话存储中。昵称显示开关不影响消息中昵称的读取。
